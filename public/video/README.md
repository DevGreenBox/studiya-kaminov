# Видео для первого экрана

Сюда кладётся ролик с горящим огнём, если заказчик его предоставит.

1. Положите файл, например `fire.webm` (или `fire.mp4`).
2. Укажите путь в `src/config/site.ts` → `heroMedia.video`:

```ts
export const heroMedia = {
  video: '/video/fire.webm',
  ...
};
```

Компонент `Hero` сам переключится на `<video autoplay muted loop playsInline>`
с постером из hero-фотографии. Пока значение `null`, пламя на реальном фото
оживляется CSS-анимацией.

Рекомендации к ролику: 6–10 секунд, бесшовный цикл, вертикальный кадр 4:5,
до 2–3 МБ, без звука.
