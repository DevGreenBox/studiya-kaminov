# Материалы от заказчика

Сюда кладутся файлы, присланные вне архива с Яндекс.Диска: фотографии на
замену, съёмка производства, логотипы.

## Замена фотографий товара

```
incoming/products/<slug>/<NN>.<jpg|jpeg|png|webp>
```

`NN` — номер кадра в галерее: `01` — главное фото, `02` — второе и так далее.
Порядок кадров задан в `scripts/image-manifest.json`.

Файл отсюда **подменяет** соответствующий кадр из архива. Архив остаётся
источником по умолчанию, поэтому пересборка изображений не затрёт присланное
заказчиком обратно архивным.

Пример: улучшенное главное фото «Дублин Премиум» кладётся как
`incoming/products/dublin-premium-white-grey/01.jpg`.

После добавления файлов:

```bash
node scripts/prepare-images.mjs <путь к распакованному архиву>
node scripts/make-covers.mjs
```

Второй скрипт пересоберёт обложки категорий, баннеры карусели и главные фото
карточек — то есть новая фотография разойдётся во все места, где она
используется.

## Замена кадров в блоках о производстве

```
incoming/content/<ключ>.<jpg|jpeg|png|webp>
```

Ключи соответствуют файлам в `public/images/production`:

| Ключ           | Где используется                                   |
| -------------- | -------------------------------------------------- |
| `hearth-wide`  | широкий кадр очага на главной и на «О нас»         |
| `stone-detail` | фотография фактуры в блоке «Почему покупают у нас» |

Файл отсюда подменяет кадр, который иначе вырезался бы из фотографии товара.
Размер вывода задан в `PRODUCTION` в `scripts/make-covers.mjs`; увеличивать
кадр скрипт не станет — если присланный снимок меньше цели, он останется
в своём размере.
