# Материалы от заказчика

Сюда кладутся файлы, которые заказчик присылает вне архива с Яндекс.Диска:
фотографии на замену, съёмка производства, логотипы.

Скрипты сюда не смотрят автоматически — файл разбирается вручную и попадает
в `public/images` через `scripts/prepare-images.mjs` или `make-covers.mjs`,
чтобы источник и кадрирование остались зафиксированными в коде.
